# Nitin Kothiyal - Personal Developer Portfolio

Modern, high-performance personal portfolio website built with HTML5, CSS3 (Modern Glassmorphism & Responsive Design), and Vanilla JavaScript.

## 🚀 Live Preview Locally
Simply double-click `index.html` or open it with any web browser (Chrome, Edge, Firefox, Brave) to view the portfolio.

Or serve via any local static server:
```bash
# Using Python
python -m http.server 3000

# Using Node.js npx
npx serve .
```

## ✨ Features
- **Modern Glassmorphic Dark/Light Mode**: Smooth theme toggling with persistent user preference in `localStorage`.
- **Dynamic Typewriter Header**: Rotating titles highlighting BCA student background and Full Stack competencies.
- **Interactive Project Showcase**: Filter projects by categories (`All`, `Full Stack`, `Frontend`, `Backend & APIs`).
- **One-Click Email Copying**: Copy email directly with a sleek toast notification.
- **Responsive Mobile First**: Customized mobile drawer menu, clean flex/grid layout, and zero third-party dependencies required to run offline.
- **SEO & Accessibility Ready**: Clean semantic HTML5 tags, meta descriptions, and accessible ARIA attributes.

## 🛠️ Personalization Checklist
1. **Name & Title**: Update `index.html` with your exact college name or university under the Education section.
2. **Projects**: Replace the sample GitHub links (`https://github.com/...`) and live demo URLs with your actual projects.
3. **Contact**: Update `nitinkothiyal@example.com` with your real email address and update your LinkedIn/Twitter links.
4. **Resume**: Put your PDF resume inside this folder (e.g., `resume.pdf`) and update the `#resume` link in `index.html`.

## 🌐 Free 1-Click Deployment
- **GitHub Pages**: Push this repo to GitHub, head to **Settings > Pages**, choose `main` branch, and save.
- **Vercel**: Import your GitHub repository into Vercel and click **Deploy**.
- **Netlify**: Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop).
